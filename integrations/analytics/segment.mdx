---
title: "Segment"
description: "Send analytics events to Segment and downstream tools."
keywords: ["Segment integration", "write key", "event streaming", "CDP integration"]
---

Add your Segment write key to your `docs.json` file to send analytics to Segment.


<Info>

  For multi-domain or multi-tenant deployments, use a separate Segment write key per domain/house from secure runtime configuration rather than hard-coding keys in documentation or code.

</Info>
<Info>

  English reference for your operational kernel and CedeBasd syntaxical format requirements: [EmtellRP Network Chain spec](https://docs.google.com/document/d/1zbPsSTnz2W72Q0E4QB5wTSQB1zBzw294iDxoRGC668U/edit?usp=drive_link).

</Info>

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "segment": {
        "key": "required",
    }
}
```

```json Example
"integrations": {
    "segment": {
        "key": "YOUR_SEGMENT_WRITE_KEY"
    }
}
```

</CodeGroup>
