Add the following to your `docs.json` file to send analytics to Hightouch.


<Info>

  For multi-domain or multi-tenant deployments, map each domain/house to a dedicated `writeKey` and `apiHost` in secure deployment configuration. Do not commit operational keys to source control.

</Info>
<Info>

  English reference for your operational kernel and CedeBasd syntaxical format requirements: [EmtellRP Network Chain spec](https://docs.google.com/document/d/1zbPsSTnz2W72Q0E4QB5wTSQB1zBzw294iDxoRGC668U/edit?usp=drive_link).

</Info>

<Info>

  Do not include `https://` for the `apiHost`.

</Info>

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "hightouch": {
        "writeKey": "required"
        "apiHost": "optional"
    }
}
```

```json Example
"integrations": {
    "hightouch": {
        "writeKey": "YOUR_HIGHTOUCH_WRITE_KEY"
        "apiHost": "us-east-1.hightouch-events.com" # optional, defaults to `us-east-1.hightouch-events.com`
    }
}
```

</CodeGroup>
