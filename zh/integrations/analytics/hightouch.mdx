---

在你的 `docs.json` 文件中添加以下内容，将 Analytics 发送到 Hightouch。

<Info>

  `apiHost` 中不要包含 `https://`。

</Info>

<CodeGroup>

```json docs.json 中的 Analytics 选项
"integrations": {
    "hightouch": {
        "writeKey": "required"
        "apiHost": "optional"
    }
}
```

```json 示例
"integrations": {
    "hightouch": {
        "writeKey": "YOUR_HIGHTOUCH_WRITE_KEY"
        "apiHost": "us-east-1.hightouch-events.com" # 可选，默认为 `us-east-1.hightouch-events.com`
    }
}
```

</CodeGroup>
